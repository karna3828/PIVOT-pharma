# Reading the Pivot — Track D, Pharma Intelligence Platform

A beginner-friendly, front-end-only prototype (HTML + CSS + vanilla JavaScript + Chart.js via CDN) that compares management narratives with reported financial evidence.

## How to run the project

1. Open the project folder in Visual Studio Code.
2. Install the Live Server extension if it is not already installed.
3. Open `index.html`.
4. Right-click inside the editor.
5. Select "Open with Live Server".
6. The website opens in the browser.
7. Use the demo credentials to log in.

**Demo credentials:** username `sunpharma_demo` · password `SunPivot@2026` (or click "Fill Demo Credentials").

## Important notes

- These are fictional prototype credentials. This is not an official Sun Pharma login and is not affiliated with Sun Pharmaceutical Industries Ltd. It is a front-end demo, not production authentication.
- All starting charts and scenarios are labelled **illustrative / requires source verification**. No company financials are included.
- Uploaded PDFs stay in the browser for the current session and are **not** automatically analyzed. Copy values and excerpts from official reports into the manual forms, with source and page number.
- Entered values, evidence excerpts and comparison rows are saved in your browser's localStorage. Do not enter sensitive documents. Use the delete buttons to clear entries.
- If the Chart.js or Font Awesome CDN is unreachable, the site stays usable; charts show a fallback message.
